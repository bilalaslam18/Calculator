# Calculator

A simple Android calculator app. Enter two numbers and perform basic arithmetic — addition, subtraction, multiplication, and division.

## Built with

- Java
- Android SDK (min SDK 24, target SDK 33)
- Gradle

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/codebybilal18/Calculator.git
   ```
2. Open the project in [Android Studio](https://developer.android.com/studio).
3. Let Gradle sync, then run the app on an emulator or a connected device.

Alternatively, build from the command line:

```bash
./gradlew assembleDebug
```

## Usage

Type a number into each of the two input fields and tap **+**, **−**, **×**, or **÷** to see the result.
